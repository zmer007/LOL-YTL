# 英雄联盟一图流编辑器 (LOL-YTL)

一个 Electron 桌面应用版的英雄联盟「一图流」可视化编辑器，支持拖拽布局、官方图标库、分组管理、框选对齐等功能，可导出 JSON 配置与高清图片。双击即用，无需服务器或 Docker。

## 功能特性

### 画布与编辑

- 自定义画布尺寸（默认 2560×1440），支持背景图上传
- 元素支持拖拽移动、角点缩放、键盘方向键微调（Ctrl+方向键小步移动）
- 原生 Canvas 导出 PNG，避免视口留白问题
- Ctrl/Cmd+点击多选元素
- 分区面板标题字号可调，导出时始终位于最底层

### 元素类型

| 类型    | 说明      | 添加方式             |
| ----- | ------- | ---------------- |
| 英雄    | 官方英雄头像  | 工具栏点击 → 从图库拖拽到画布 |
| 装备    | 官方装备图标  | 工具栏点击 → 从图库拖拽到画布 |
| 符文    | 官方符文图标  | 工具栏点击 → 从图库拖拽到画布 |
| 召唤师技能 | 闪现、引燃等  | 工具栏点击 → 从图库拖拽到画布 |
| 文字标签  | 可编辑文字   | 双击画布空白处          |
| 分区面板  | 标题+内容区块 | 工具栏点击            |

### 图片库

- 内置官方资源（英雄/装备/符文/召唤师技能），一键从 Riot Data Dragon 更新
- 自定义分组，支持折叠/展开
- 拖拽图标在分组间移动（全部组仅支持复制）
- 右键菜单：移动到/复制到指定分组

### 配置管理

- 配置保存/加载/删除（JSON 持久化到用户数据目录）
- 导出 JSON 配置文件，可分享给他人导入

## 技术栈

- **前端**：原生 HTML + CSS + JavaScript（单文件 `web/index.html`）
- **桌面壳**：Electron（主进程内嵌本地 HTTP 服务，替代原 Go 后端）
- **后端**：Node.js http 模块（`server.js`，零第三方依赖）
- **打包**：electron-builder（NSIS 安装版 + portable 便携版）

## 项目结构

```
.
├── main.js              # Electron 主进程入口
├── server.js            # 内嵌本地服务 (API + 静态资源)
├── package.json         # 依赖与打包配置
├── build/
│   └── icon.png         # 应用图标
├── web/
│   └── index.html       # 前端单文件应用
├── assets/              # 应用自带的图标资源 (首次启动复制到用户数据目录)
└── README.md
```

## 快速开始

### 开发运行

```bash
npm install
npm start
```

### 打包 exe

```bash
npm run dist
```

产物输出到 `dist/`：

- `LOL-YTL-Setup-1.0.0.exe` — NSIS 安装版
- `LOL-YTL-1.0.0.exe` — portable 便携版（免安装，单文件）

> 注：国内网络打包需设置镜像：
> `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`
> `ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/`

## 数据存储

- 图标缓存与保存的配置存放在用户数据目录（`%APPDATA%/LOL-YTL/assets`），升级或重装不丢失
- 应用自带一套 16.20.1 版本的官方图标，首次启动自动复制，开箱即用
- 在应用内点击「更新」可从官方 Data Dragon 拉取最新版本图标

## 使用指南

### 添加图片元素

1. 点击左侧工具栏的「英雄」「装备」「符文」或「召唤师技能」
2. 右侧属性面板显示对应图库
3. 从图库中拖拽图片到画布，即在落点创建元素

### 添加文字

- **双击画布空白处**即可在该位置创建文字标签

### 框选与多选

- 在画布空白处按下鼠标并拖动，框选多个元素
- 按住 Ctrl/Cmd 点击可逐个加选
- 右侧属性面板显示对齐工具栏，支持 8 种对齐/分布

### 键盘微调

- 方向键：移动 10px
- Ctrl+方向键：移动 1px

### 管理图库

1. 点击左侧「图片库」打开管理弹窗
2. 点击「更新」从官方拉取最新图标
3. 拖拽图标在分组间整理，右键可复制/移动到其他分组

### 导出

- 点击顶栏「导出 PNG」下载画布图片
- 点击「导出 JSON」保存当前配置文件
