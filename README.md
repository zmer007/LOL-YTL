# 英雄联盟一图流编辑器

一个基于 Web 的英雄联盟「一图流」可视化编辑器，支持拖拽布局、官方图标库、分组管理、框选对齐等功能，可导出高清图片。

## 功能特性

### 画布与编辑
- 自定义画布尺寸（默认 1920×1080），支持背景图上传
- 元素支持拖拽移动、角点缩放、键盘方向键微调
- 原生 Canvas 导出 PNG，避免视口留白问题

### 元素类型
| 类型 | 说明 | 添加方式 |
|------|------|----------|
| 英雄 | 官方英雄头像 | 工具栏点击 → 从图库拖拽到画布 |
| 装备 | 官方装备图标 | 工具栏点击 → 从图库拖拽到画布 |
| 符文 | 官方符文图标 | 工具栏点击 → 从图库拖拽到画布 |
| 召唤师技能 | 闪现、引燃等 | 工具栏点击 → 从图库拖拽到画布 |
| 文字标签 | 可编辑文字 | 双击画布空白处 |
| 分区面板 | 标题+内容区块 | 工具栏点击 |

### 图片库
- 内置官方资源（英雄/装备/符文/召唤师技能），一键从 Riot Data Dragon 更新
- 自定义分组，支持折叠/展开
- 拖拽图标在分组间移动（全部组仅支持复制）
- 右键菜单：移动到/复制到指定分组
- IndexedDB 持久化，刷新不丢失

### 多选与对齐
- 鼠标框选多个元素
- 批量移动、批量删除
- 8 种对齐/分布：左/水平居中/右、顶/垂直居中/底、水平平均分布/垂直平均分布

## 技术栈

- **前端**：原生 HTML + CSS + JavaScript（单文件 `web/index.html`）
- **后端**：Go（标准库 net/http，零第三方依赖）
- **数据**：IndexedDB（浏览器端图库持久化）
- **部署**：Docker / Docker Compose

## 项目结构

```
.
├── server/              # Go 后端
│   ├── main.go          # 入口
│   ├── handler.go       # HTTP 路由处理
│   ├── cache.go         # 官方资源缓存逻辑
│   ├── config.go        # 全局配置
│   └── go.mod
├── web/
│   └── index.html       # 前端单文件应用
├── assets/              # 图片缓存目录（运行时生成）
├── build/               # 编译产物
├── Dockerfile           # 多阶段构建
├── docker-compose.yml   # 一键部署
├── Makefile             # 常用命令封装
└── README.md
```

## 快速开始

### 本地开发

```bash
# 编译并运行
make run

# 或手动编译
cd server && go build -o ../build/server . && cd ..
./build/server
```

启动后访问 http://localhost:8765

### Docker 部署

```bash
# 构建镜像并启动
make docker-up

# 查看日志
make docker-logs

# 停止容器
make docker-down
```

容器默认映射 8765 端口，`assets` 目录通过卷挂载持久化官方图片缓存。

## 使用指南

### 添加图片元素
1. 点击左侧工具栏的「英雄」「装备」「符文」或「召唤师技能」
2. 右侧属性面板显示对应图库
3. 从图库中拖拽图片到画布，即在落点创建元素

### 添加文字
- **双击画布空白处**即可在该位置创建文字标签

### 框选与对齐
1. 在画布空白处按下鼠标并拖动，框选多个元素
2. 右侧属性面板显示对齐工具栏
3. 点击对齐按钮或按 Delete 批量删除

### 管理图库
1. 点击左侧「图片库」打开管理弹窗
2. 点击「🔄 更新」从官方拉取最新图标
3. 点击「+分组」创建自定义分组
4. 拖拽图标在分组间整理，右键可复制/移动到其他分组

### 导出
- 点击顶栏「导出 PNG」下载画布图片

## 配置

配置项位于 `server/config.go`：

| 常量 | 默认值 | 说明 |
|------|--------|------|
| `ListenAddr` | `:8765` | 服务监听端口 |
| `DefaultVersion` | `16.10.1` | Data Dragon 默认版本 |
| `DownloadConcurrency` | `6` | 图片下载并发数 |
| `DDragonBase` | `https://ddragon.leagueoflegends.com/cdn` | 官方 CDN 地址 |

修改后需重新编译。

## API 接口

| 路径 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 前端页面 |
| `/api/version` | GET | 版本信息 |
| `/api/library` | GET | 获取图库列表（含各类型图片） |
| `/api/cache` | POST | 触发官方资源缓存 |
| `/assets/*` | GET | 访问缓存的图片文件 |
